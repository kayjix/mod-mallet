# 0016 Automation and dependencies

- Status: accepted
- Date: 2026-11-15

## Context

Two things make a project hard to join and expensive to keep: checks that
behave differently on each machine, and dependencies nobody looked at.

## Decision

**Automation**

- Everything beyond `cargo build` is a command of `cargo xtask`, written in
  Rust. There are no shell scripts, so Windows and Linux behave the same.
- `cargo xtask ci` runs every check that CI runs. CI calls the same command.
- Files derived from code are regenerated by `cargo xtask gen` and verified
  by `cargo xtask gen --check`.
- Git hooks (lefthook) run the fast checks before a commit and the full set
  before a push.
- Commits follow Conventional Commits, checked by a hook, so that release
  notes can be generated.

**Dependencies**

- A dependency is added **when the milestone that needs it starts**, not in
  anticipation.
- Versions are declared once, in `[workspace.dependencies]`.
- `cargo deny` checks every dependency for a compatible license, known
  security advisories, and unexpected sources. It runs in CI.
- Before adding a dependency, check that it is maintained, what it pulls in,
  and whether a few lines of our own code would do. The steps are in
  [Dependencies](../contributing/dependencies.md).
- The compiler version is pinned in `rust-toolchain.toml` and raised
  deliberately.
- Dependabot proposes updates weekly.

**Lints**

- Rust: Clippy's `all` and `pedantic` groups as warnings, which CI treats as
  errors, plus the robustness lints of ADR 0013. Exceptions are listed in
  the workspace `Cargo.toml` with a reason.
- TypeScript, JSON and CSS: Biome with its recommended rules, and
  TypeScript's strict mode.
- Public Rust items must be documented.

## Consequences

- A new contributor runs one command to know whether their change is
  acceptable.
- Automation code is compiled and linted like everything else.
- Release automation is deliberately absent until there is something to
  release.
- TOML files are not checked by a formatter: the one tried did not find
  files on Windows. They are kept tidy by review.
